# E-LKPD Matematika – Penjumlahan Berulang (Kelas 3 SD)

E-LKPD (Elektronik Lembar Kerja Peserta Didik) Matematika interaktif berbasis web untuk siswa Kelas 3 SD.  
Materi: **Penjumlahan Berulang (Perkalian)**

## 🔗 Akses Online
👉 **[Buka E-LKPD](https://[username].github.io/[repo-name]/)** *(ganti dengan URL GitHub Pages Anda)*

## 📚 Fitur
- **Halaman Cover** – siswa memasukkan nama & kelas
- **Petunjuk** – cara penggunaan E-LKPD
- **CP & TP** – Capaian dan Tujuan Pembelajaran
- **Materi** – penjelasan penjumlahan berulang dengan contoh visual
- **Latihan Soal Interaktif**:
  - Isi titik-titik (fill in blanks)
  - Lengkapi tabel
  - Game cocokkan gambar (drag & drop / tap di HP)
- **Refleksi** – penilaian diri siswa dengan bintang
- **Identitas Pengembang**

## 📱 Responsif
Tampilan menyesuaikan otomatis di HP, tablet, dan komputer.

## 🗂️ Struktur File
```
e-lkpd/
├── index.html          ← Halaman cover
├── petunjuk.html       ← Halaman petunjuk
├── cptp.html           ← Capaian & Tujuan Pembelajaran
├── materi.html         ← Materi pembelajaran
├── latihan.html        ← Latihan soal interaktif
├── refleksi.html       ← Refleksi belajar
├── pengembang.html     ← Identitas pengembang
├── css/
│   └── style.css       ← Stylesheet utama
├── js/
│   └── shared.js       ← JavaScript utilitas bersama
└── assets/
    └── images/
        └── mascot.png  ← Gambar maskot
```

## 🚀 Deploy ke GitHub Pages
1. Upload semua file ke repository GitHub
2. Buka **Settings → Pages**
3. Pilih **Source: Deploy from a branch**, branch: `main`, folder: `/ (root)`
4. Klik **Save** → tunggu beberapa menit
5. Website aktif di `https://[username].github.io/[repo-name]/`

## 🛠️ Teknologi
- HTML5, CSS3 Vanilla, JavaScript (ES6+)
- Google Fonts (Nunito, Fredoka One)
- Tanpa framework/library eksternal
